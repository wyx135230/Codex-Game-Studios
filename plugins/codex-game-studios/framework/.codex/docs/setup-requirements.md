# Setup requirements

Use the root README for installation. Python 3.11+, Bash 3.2+ with awk/sed/grep/find, Git, and a local Codex client are required. Windows needs Git Bash; set STUDIO_BASH if automatic discovery fails. Engine builds require the chosen editor and its test framework. Plugin installation uses plugin.json, .codex-plugin/plugin.json and hooks/hooks.json, with hook trust reviewed in Codex. No <plugin-root>/framework/.codex/settings.json is used.
